---
name: Case File visual direction
description: Approved visual hierarchy for the mobile Case File conversation.
---

Keep the mobile Case File conversation-first, calm, and clinically professional. Patient context and vitals should remain compact and scannable so messages have room. Attachments should look actionable. Signed Clinical Advisories must have stronger permanent-record styling than ordinary messages.

**Why:** The user selected the “Calm Conversation” direction over a denser record-first clinical timeline after comparing both designs with the prior screen.

**How to apply:** Preserve this hierarchy when changing the Case File or adding new message types. Do not let patient context panels dominate the conversation, and never style a signed Clinical Advisory like an editable chat bubble.
