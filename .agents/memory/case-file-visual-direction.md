---
name: Case File visual direction
description: Approved visual hierarchy for the mobile Case File conversation.
---

Use the unified warm Coral/Plum consumer design across the mobile Case File, not a separate cool-toned “calm conversation” theme. Keep context and vitals compact so messages retain space. Attachments should be actionable, and signed Clinical Advisories must remain visually distinct as permanent records.

**Why:** The newer approved Perfusion reference explicitly replaces the earlier split palette with one consistent warm system. Clinical Advisories still represent signed, immutable records.

**How to apply:** Use the shared Coral/Plum tokens for the header, chat, cards, and controls. Keep clinical context concise, and never style a signed Clinical Advisory like an editable chat bubble.

For Case File chat, show images and videos as clean, bounded media previews rather than filename-first file cards. Portrait media should have enough height to be recognizable inside the conversation, and filenames should not appear in chat or its media viewer. A WhatsApp example was supplied only to illustrate media placement and proportions, not to adopt its palette, fonts, or other styling.

**Why:** People reviewing clinical conversations need to recognize the media without opening every file, while raw upload names add noise and can expose unnecessary information.

**How to apply:** Retain original filenames in private storage/downloads, but display neutral media type labels where needed. Keep visual treatments in Perfusion's existing design system.
