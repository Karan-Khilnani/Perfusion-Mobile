We need to fix the clinical information/data structure in BOTH the Perfusion WEB APP and MOBILE APP.

This is a clinical data-flow correction.

IMPORTANT:
Do NOT treat this as only a UI rename/reordering task.

The current implementation is incorrectly duplicating clinical information between:
- Presenting Complaint
- Clinical Summary

We need to separate these concepts properly and make sure the data entered during Patient Booking flows into the correct sections of the Provider Case File.

==================================================
1. CURRENT PROBLEM
==================================================

Currently, in the Provider Case File:

PRESENTING COMPLAINT

and

CLINICAL SUMMARY

are appearing with the same information.

Example currently:

Presenting Complaint:
"Known case DM presented with chest pain"

Clinical Summary:
"Known case DM presented with chest pain"

This is incorrect because these are different clinical concepts.

They must NOT be automatically populated with the same value.

==================================================
2. DEFINITIONS / REQUIRED MEANING
==================================================

Use these meanings consistently across Web, Mobile, backend, booking, and Case File.

PRESENTING COMPLAINT:
The patient's main complaint/reason for seeking medical attention.

Example:
"Acute chest pain and breathlessness for 2 days"

PRESENT ILLNESS:
The history/details of the patient's current illness or current episode.

Example:
"Patient developed central chest pain 2 days ago, associated with breathlessness. Pain increased since morning."

COMORBIDITIES / PAST ILLNESS:
Relevant existing diseases, past illnesses, chronic conditions, or other important medical conditions.

Example:
- Type 2 Diabetes
- Hypertension
- Asthma

CLINICAL DETAILS:
Relevant examination and investigation information.

This should contain the clinical examination findings and investigation information provided during booking.

Example:
Examination:
"BP 128/82, HR 96, RR 18"

Investigations:
"ECG shows..."

PROVISIONAL DIAGNOSIS:
The referring/seeking hospital's provisional/working diagnosis.

Example:
"? ACS"

CLINICAL SUMMARY:
A relevant overall clinical summary/history that gives the Provider a concise understanding of the case.

It must NOT simply duplicate Presenting Complaint.
