# PERFUSION MOBILE — FIX UNREADABLE / DIMMED TEXT AND CONTENT

There is a serious visual bug in the current mobile app.

The text and content across the app are appearing extremely dark/dim and are difficult to read.

I have provided screenshots showing the problem.

IMPORTANT:
DO NOT redesign the app.
DO NOT change navigation.
DO NOT change APIs, backend logic, or business logic.
DO NOT change unrelated screens.

Fix ONLY the readability/visibility problem.

## CURRENT PROBLEM

In the screenshots:

1. Consultation cards are extremely dark and their text is barely visible.
2. Case File/chat content is extremely dark and difficult to read.
3. File/media information is barely visible.
4. Some buttons and icons are also excessively dim.
5. The overall screen appears to have an unintended dark overlay/opacity applied over normal content.

The header and some primary elements are visible, but the content underneath is being rendered far too dark.

## IMPORTANT — FIND THE ROOT CAUSE

Do NOT simply make every Text color white.

First inspect the implementation and determine WHY the content is being dimmed.

Check for:

- parent `opacity`
- `opacity` values applied to containers
- semi-transparent overlays
- dark backdrop Views
- Modal/backdrop layers
- accidental `rgba(..., alpha)` backgrounds
- `backgroundColor` alpha values
- `TouchableOpacity` / press-state opacity
- disabled-state styling being applied permanently
- theme colors incorrectly resolving to dark/low-contrast values
- `Animated.View` opacity
- loading overlays
- modal overlays
- z-index/elevation layering
- absolute-positioned overlay Views
- `pointerEvents`
- dark-mode styles accidentally being applied in the wrong state
- conditional rendering that leaves a dimming layer visible
- any parent container that is reducing the opacity of its children

React Native opacity on a parent also affects its child content, so check the component hierarchy rather than only changing individual Text colors.
