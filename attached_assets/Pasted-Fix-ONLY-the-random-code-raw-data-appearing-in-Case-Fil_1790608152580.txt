==================================================
CURRENT BUG
==================================================

In the Case File Chat, when the Provider or Seeker sends a message, the Chat sometimes displays random codes/raw data before the actual message.

For example, instead of displaying only:

"Adv WCG 2d ECHO and urgent Trop I"

the Chat may display something similar to:

{"advisoryId":"655639c2-4e20-4fff-9c06-242130a0f5a5","narrative":"Adv WCG 2d ECHO and urgent Trop I"}

The user should NEVER see this raw JSON/object/code.

The Chat should display only the actual human-readable message:

"Adv WCG 2d ECHO and urgent Trop I"

==================================================
REQUIRED BEHAVIOR
==================================================

When Provider sends a normal text message:

SHOW:
The exact human-readable text typed/sent by the Provider.

When Seeker sends a normal text message:

SHOW:
The exact human-readable text typed/sent by the Seeker.

Do NOT show:

- JSON
- Object representations
- IDs
- UUIDs
- Database IDs
- advisoryId
- bookingId
- consultationId
- Internal metadata
- Raw API response
- Serialized objects
- Debug information
- Internal codes
