We need to implement a new PATIENT COMORBIDITIES / PAST ILLNESS feature across BOTH the Perfusion WEB APP and MOBILE APP.

IMPORTANT:
This feature must work end-to-end across:

SEEKER BOOKING FORM
        ↓
SHARED BACKEND / DATABASE
        ↓
PROVIDER CASE FILE
        ↓
WEB + MOBILE

The Seeker Hospital should enter the patient's relevant comorbidities/past illnesses during the Patient Booking process.

The Provider should then automatically see the same information in the Patient Case File.

The Provider must NOT need to manually re-enter the information.

==================================================
1. CORE REQUIREMENT
==================================================

Add a field to the Patient Booking Form:

"Comorbidities / Past Illness"

The Seeker Hospital enters the patient's relevant comorbidities/past illnesses while creating the consultation/booking.

After the booking is submitted:

The information must be saved to the shared backend/database and associated with that specific patient/consultation.

When the Provider opens the Case File:

The same information must automatically appear under:

"Comorbidities / Past Illness"

The Provider should only be viewing the information provided by the Seeker.

Do NOT create a second Provider-specific comorbidities field that requires re-entry.

==================================================

==================================================

This feature must be implemented for:

1. Web Seeker Booking Form
2. Mobile Seeker Booking Form
3. Web Provider Case File
4. Mobile Provider Case File

Architecture should be:

WEB BOOKING
      ↓

      │
MOBILE BOOKING

SHARED PATIENT/CONSULTATION DATA
      ↓
WEB PROVIDER CASE FILE
      +
MOBILE PROVIDER CASE FILE

Do NOT create separate Web and Mobile comorbidity data.
