Navigation model

Solid screen frames represent registered pages. Arrows show the principal forward journey; users may navigate backward or jump through role navigation.

Public discovery, authentication, and onboarding

The entry journey introduces services, starts bookings, authenticates users, and resolves required account state before role dashboards.

Public / shared
Landing/

Primary marketing and service-discovery entry point.

  • Explore services
  • Browse consultants
  • Browse lab tests
  • Log in or register
Consultants/consultants

Public specialist discovery and booking entry.

  • Browse consultants
  • View public profiles
  • Start booking
  • Redirect to login if needed
Lab Tests/lab-tests

Public diagnostic-test catalog and booking entry.

  • Browse available tests
  • View test details
  • Start a booking
  • Log in or register
Login/login

Authenticate an existing Perfusion account.

  • Enter credentials
  • Sign in
  • Continue to registration
  • Resolve account state
Register/register

Create a new account using the current registration flow.

  • Enter account details
  • Create account
  • Continue to role selection

Assign the account’s intended application role.

  • Choose account role
  • Continue to profile setup
Complete Profile/complete-profile

Collect additional identity and role-specific profile data.

  • Enter profile details

  • Continue verification
Verify Email/verify-email

Verify account ownership before protected access.

  • Enter verification value

  • Review approval status

Present and capture the required current platform agreement.

  • Read agreement
  • Accept current version
  • Continue to role dashboard

  • Review verification result
  • Inspect prescription metadata

  • Enter protected application
  • Use role navigation
Alternate public route: /home is a smaller secondary home screen. Unmatched URLs render the Not Found page.

Care Seeker journey

The user layout provides Dashboard, Lab Tests, Consultation, Teleradiology, Orders, Billing, and Profile navigation.

Care Seeker
User Dashboard/user

Overview of upcoming and recent healthcare activity.

  • Review bookings
  • Join eligible video consultation
  • Open reports and prescriptions
Consultations/user/consultation

Browse consultants and begin a consultation booking.

  • Browse and filter consultants
  • View consultant information
  • Select Book
Consultation Booking/user/consultation/:id/book

Collect booking details, select a slot, and confirm.

  • Select time slot
  • Enter patient details
  • Complete payment where required
  • Confirm booking
Orders/user/orders

Track bookings, consultation outcomes, and clinical documents.

  • Review status
  • Join consultation room
  • View/download reports and prescriptions
  • Book again
Lab Tests/user/labs

Browse the authenticated diagnostic-test catalog.

  • Browse tests
  • Select a test
  • Open lab booking
Lab Booking/user/labs/:id/book

Submit patient and scheduling information for a selected test.

  • Enter patient information
  • Enter booking details
  • Confirm request
Teleradiology/user/teleradiology

Access the currently implemented radiology-service flow.

  • Review service information
  • Initiate applicable request
Billing/user/billing

Review seeker billing and payment records.

  • View charges
  • Review payment records
  • Inspect billing history
Profile/user/profile

Maintain the Care Seeker account and personal information.

  • View details
  • Edit personal information
  • Save changes
  • Log out
Video Room/video/:roomId

Shared live consultation room opened from an eligible booking.

  • Join consultation
  • Use live communication controls
  • Leave room
Primary seeker flow: Dashboard → Consultant discovery → Booking → Orders → Video room / clinical documents. Lab, radiology, billing, and profile are parallel navigation destinations.

Care Provider journey

The provider layout supplies Dashboard, Bookings, Services where eligible, Billing, and Profile. Consultant and teleradiology provider types do not receive Services navigation.

Care Provider
Provider Onboarding/provider/onboarding

Create or complete a provider’s professional profile.

  • Enter professional details
  • Submit provider profile
  • Continue approval workflow
Provider Dashboard/provider

Operational overview of recent bookings and provider activity.

  • Review recent activity
  • Open assigned bookings
  • Access provider operations
Provider Bookings/provider/bookings

Process assigned consultations and other supported bookings.

  • Filter and inspect bookings
  • Review patient documents
  • Update status
  • Join video room
  • Create reports/prescriptions
Provider Services/provider/services

Configure offered services and availability for eligible provider types.

  • Manage services
  • Configure pricing
  • Manage availability
Provider Billing/provider/billing

Review provider earnings and billing-related information.

  • Review billing records
  • Inspect payment information
Provider Profile/provider/profile

Maintain provider account and professional profile information.

  • View account details
  • Edit profile
  • Save changes
  • Log out
Video Room/video/:roomId

Shared live consultation room opened from an eligible provider booking.

  • Join consultation
  • Use live communication controls
  • Leave room
Primary provider flow: Onboarding/approval → Dashboard → Assigned booking → Patient material and documentation → Video room → Booking completion. Services, billing, and profile are parallel destinations.

Implementation boundaries

This document reflects currently registered web routes and observed page responsibilities. It does not represent proposed backlog items as implemented behavior.

Critical-care page files exist in the source tree but are not currently registered in the application router, so they are excluded from the active navigation flow. Exact redirects after registration may vary based on role, verification, approval, and agreement state.
